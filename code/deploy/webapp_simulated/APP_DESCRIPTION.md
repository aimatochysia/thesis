# CardioMonitor -- Application Description

CardioMonitor is a web-based application designed to assist in monitoring and classifying electrocardiogram (ECG) heartbeats in real time by utilizing machine learning technology. Powered by a Context-Aware CNN1D model optimized and exported to the ONNX format, this application provides accurate beat-by-beat classification based on ECG signal data, distinguishing between normal and abnormal heartbeats using contextual information from surrounding beats.

Users simply need to open the application in a browser and start the monitoring session. CardioMonitor will continuously visualize the incoming ECG signal on an interactive canvas while analyzing each heartbeat as it arrives. If an abnormal heartbeat is detected, the application immediately flags it with a visual indicator and displays the probability score that triggered the classification, allowing users to identify potential cardiac irregularities early and take appropriate action.

The application employs a 7-beat rolling context window, meaning each heartbeat is classified not in isolation but by considering the three preceding and three following beats. This context-aware approach improves classification accuracy and reduces false positives compared to single-beat analysis. A dedicated beat snapshot panel shows exactly what the model receives as input, providing full transparency into the classification process.

CardioMonitor also includes various supporting features to enhance usability. The playback speed can be adjusted from 0.1x to 10x, enabling users to slow down for detailed inspection or speed through longer recordings efficiently. A history navigation system with drag-to-scroll functionality allows users to review any past segment of the recording at any time, while a live mode button instantly returns to the current position. Real-time statistics are displayed throughout the session, including total beats processed, normal and abnormal counts, current heart rate (BPM), model accuracy against ground truth annotations, and a count of false predictions.

To support data management and further analysis, CardioMonitor provides an auto-batch export system that periodically saves ECG strip segments. These batches can be downloaded together as a single ZIP file containing PNG images of the ECG waveform with annotated R-peak markers, ready for archival or review by healthcare professionals.

Designed for easy deployment across different environments, CardioMonitor runs as a lightweight Docker container that works identically on macOS, Linux, and Windows. With a single command, healthcare facilities, research labs, or individual practitioners can have the application up and running without worrying about dependency management or platform-specific configuration. This makes CardioMonitor not only a tool for understanding and monitoring cardiac rhythm but also a practical aid for medical professionals seeking to detect abnormalities and support clinical decision-making more efficiently.
